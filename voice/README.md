# 真正的电话号码（客人用手机拨打，AI 接听）

网站上的电话按钮是**浏览器内语音通话**：客人点按钮，用麦克风和扬声器和助手说话，不产生电话费，也不需要电话号码。

如果你还想要一个**真的电话号码**，让客人用手机拨打后由 AI 接听，需要一个付费的语音 AI 平台。GitHub 本身做不到这件事。我没有开通或测试过任何一家平台，下面是做法的概要，具体界面和价格请以平台官网为准。

## 步骤概要
1. 选一个语音 AI 电话平台并注册。常见的有 Vapi、Retell AI、ElevenLabs Agents、Twilio（自己搭）。比较一下英国号码（+44）的月租、每分钟价格和英式英语语音。
2. 在平台里租一个英国号码，新建一个语音助手，语言选 English (UK)，语音选一个英式女声或男声。
3. 把 `phone-agent-prompt.md` 的全部内容粘贴到助手的系统提示（system prompt）里。把其中的 `{{current date and time in London}}` 换成平台提供的"当前时间"变量；如果平台没有，就删掉这一句，并让助手在订座前先问客人要哪一天。
4. 订座和点餐要靠"工具调用"。在平台里添加两个自定义工具（custom tool / webhook），地址都是 `https://你的worker地址/tool`，方法 POST，请求头加 `x-secret: 你设置的 PHONE_TOOL_SECRET`。请求体格式：
   - `{"name":"submit_booking","input":{"name":"…","phone":"…","date":"2026-11-03","time":"19:30","guests":4,"seating":"table","notes":"…"}}`
   - `{"name":"submit_order","input":{"name":"…","phone":"…","items":[{"id":"lkarahi","size":"½ kg","qty":1}],"pickup":"asap"}}`
   各平台发送的格式不一样，如果平台不能直接发这种格式，需要在 worker 里再加一层转换。
5. 在 Worker 的设置里添加 `PHONE_TOOL_SECRET`。
6. 拿自己的手机打这个号码，把订座、点餐、问营业时间、问过敏原都试一遍，再对外公布。
7. 公布后，把号码填到 `index.html` 里的 `aiPhone`，通话界面就会显示这个号码。

## 上线前要注意
- 开场白要说明这是自动语音助手（提示词里已经写了）。
- 如果平台会录音或保存通话文字，要在开场白或网站隐私说明里告知客人，并遵守英国 UK GDPR 的要求。
- 订座和点餐只是"把请求发给餐厅"，餐厅必须在通知渠道（Slack、Discord、邮件或 Zapier 流程）里看到并回电确认。助手不会说订座已确认。
- 设置每月费用上限，并先用测试号码试几天。
